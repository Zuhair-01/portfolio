# Portfolio Site

Personal portfolio: AI Engineering & Cybersecurity student. Static HTML/CSS,
no build step, deployed via GitHub Pages.

## Structure

- `index.html` — home (hero, projects, about, skills, contact)
- `projects/*.html` — case study per project
- `resume.html` — ATS-friendly resume, printable to PDF

## Local development

No build step. Serve with any static server, e.g.:

```bash
python -m http.server 8080
```
