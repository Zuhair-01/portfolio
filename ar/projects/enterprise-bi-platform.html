الأعمال / Enterprise BI Platform

بيانات وذكاء أعمال

Enterprise BI Platform

لوحة مؤشرات تعتمد خط بيانات فعليًا: ملفات CSV، ثم تحقق وتنظيف وإزالة تكرار وتحويل، ثم نموذج قراءة ولوحة مؤشرات. ليست مجرد بيانات JSON مصطنعة موضوعة مباشرة في الواجهة.

شاهد المستودع ↗

01المشكلة

التقارير اليدوية تجمع أرقامًا من مصادر متعددة دون إظهار الصفوف المكررة أو القيم غير الصالحة قبل وصولها إلى اللوحة.

02الحل

يعالج خط Python صادرات CSV بالتحقق والتنظيف وإزالة التكرار والتحويل إلى نموذج JSON موحد، ثم تعرض واجهة Next.js ملخصًا تنفيذيًا وتحليلات أعمق.

03البنية

ملفات CSV خام ← تحقق من الحقول والتواريخ ← تنظيف مع تسجيل الأخطاء ← إزالة المفاتيح المكررة ← تجميع وحساب المؤشرات ← ملف bi_dataset.json تقرؤه مكونات الخادم.

04التحقق

أدخل مولد البيانات الاصطناعية ثلاث مشكلات مقصودة: صفًا مكررًا، واسمًا مطلوبًا فارغًا، وتاريخًا غير صالح. كشفها الخط وسجل حقلًا نُظف وصفًا مكررًا أُزيل؛ بقي 139 موظفًا بعد التنظيف.

05قرارات هندسية

ملف JSON مناسب لعرض اصطناعي ثابت دون قاعدة مستضافة. صُمم مسار الكتابة بحيث يمكن استبداله لاحقًا. للواجهة نظام ألوان Meridian مخصص بدل المظهر الافتراضي للقالب.

06الأمان والحدود

لا بيانات أشخاص أو أموال حقيقية ولا مفاتيح API مطلوبة للعرض. ملف JSON ليس قاعدة إنتاجية تنمو باستمرار؛ المرشحات الحالية على مستوى القسم ولا تشمل كل نطاقات التاريخ ووحدات الأعمال.
